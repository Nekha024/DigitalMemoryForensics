# Memoir_query.py
from Memoir import ForensicRAG

rag = ForensicRAG(
    dump="evidence/dump_07.raw",
    embedder="bge-large-en",
    store="qdrant://localhost:6333",
    llm="gpt-4o",

// FAQ

Questions, answered.

Is Memoir court-admissible? +

Yes. Every retrieval is hash-verified and Ed25519-signed. We follow NIST 800-86 and ISO 27037 guidelines, and outputs include a full audit trail.

Can I run it offline / air-gapped? +

Absolutely. The Agency tier ships with local LLMs (Llama 3, Mistral) and on-prem vector stores (Qdrant/Chroma). No external calls required.

Which memory acquisition tools are supported? +

LiME, WinPMEM, AVML, DumpIt, Magnet RAM Capture, and any tool producing raw or LiME format. We auto-detect profiles via Volatility 3.

Does the LLM hallucinate forensic findings? +

Memoir is grounded — every claim is constrained to retrieved context with offset/PID citations. Findings without citations are flagged and discarded.

How is data privacy handled? +

Evidence never leaves your environment in on-prem mode. SaaS tier is SOC2 Type II, encrypted at rest (AES-256) and in transit (TLS 1.3).
